# Valley Lot Finder

A map of vacant, for-lease, abandoned and closed properties with parking lots around the Phoenix metro. Tap a pin to see a Street View photo of the entrance, the address, and a NAVIGATE button.

Live: https://bsaxon430.github.io/valley-lot-finder-/

Pins live in `lots.json`. Street View photos use the key in `config.js` (restricted to this site).

Map imagery © Esri, Maxar, Earthstar Geographics. Street-level photos © Google. Roads and labels © Esri.

## Export the pins
- Spreadsheet (CSV): https://bsaxon430.github.io/valley-lot-finder-/export/valley-lots.csv
- Google My Maps / Google Earth (KML): https://bsaxon430.github.io/valley-lot-finder-/export/valley-lots.kml
- Raw data (JSON): https://bsaxon430.github.io/valley-lot-finder-/lots.json

To build your own map: go to mymaps.google.com → Create a new map → Import → upload the KML (or the CSV, choosing Latitude/Longitude as the location columns).
