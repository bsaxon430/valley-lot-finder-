# Valley Lot Finder

A map of vacant, for-lease, abandoned and closed properties with parking lots around the Phoenix metro. Tap a pin to see a Street View photo of the entrance, the address, and a NAVIGATE button.

Live: https://bsaxon430.github.io/valley-lot-finder-/

Pins live in `lots.json`. Street View photos use the key in `config.js` (restricted to this site).
